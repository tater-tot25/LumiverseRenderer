# Lumiverse
A lightweight volume rendering application for the Oculus Quest 2 and up.


# Features 

* Reads .raw files and can also prepopulate settings using .mhd files.
* Customizable transfer function with several preset color maps.
* Cook Torrance Reflectence Model for shading volume isosurfaces.
* Subsurface Scattering with customizable parameters
* Adjustable table to work on
* Physical Dials for tuning size and a transfer function threshold
* You can play snake on the TV if you get bored

# Controls

* Left stick to move
* Grip to grab dials, move table, and grab the volume.
* Trigger to select UI elements
* The four face buttons, X, Y, B, and A, hide and show the four different UI panels

# Adding Custom Files
* The application creates a folder at _/sdcard/Documents/VolumeRenderer/_
* Add files here for them to show up on the load panel
